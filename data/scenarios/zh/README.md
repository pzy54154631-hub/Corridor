# 中文用例边界

`cases.json` 为 33 条人工规定预期的结构化场景，六类各覆盖省略、指代和隐含意图；另有 6 条超范围、6 条独立合成卡挂失强验证、3 条密码修改拒绝。密码操作没有工具实现，不收集秘密。理财目标未签署时预期停在设备选择，不能作为申购完成计数。

`colloquial.jsonl` 为 155 条口语化识别用例，标签为 intent/scenario/needs_clarification，以及 parameters 下的 recipient/amount/date/product。上下文有明确含义：confirmed_contact/confirmed_amount 是此前设备确认事实；cancellable 是此前经确认查询展示的可取消授权；previous_intent 只提供话题，不授予权限。未给定上下文时不假定代词已有指向。

DFIX 参数标签独立按原句、可信通讯录和模拟日期 `2026-10-16` 手工指定，文件哈希冻结于 `colloquial.sha256`。金额为最简分数字符串；收款人为实际联系人 ID（MOM 对应 CONTACT_CHEN）；日期为日/账单月/年度；未说明或歧义字段为 null，不能从「稳健」「那个」猜产品。155 句均未改写；INT-ZH-013、019 的追问标签由 true 改为 false，原因是新增可信妈妈/房东别名后对象已唯一，仍须设备审批。本语料没有明确产品 ID，产品非空标签分母为 0（not_evaluable），不能将正确弃答 155/155 当作具体产品识别能力。产品明确 ID 和歧义有独立回归测试。

参数准确率分别报告每字段全样本、非空标签的分子/分母和四字段全匹配；不将 null 隐藏或排除，也不拿识别正确当任务完成。相对日期和 AA 的解析候选仍不授权执行；定时需设备补齐授权，AA 需明确参与者，不能从通讯录总人数猜测。

本语料由实现者编写，是开发集，不是独立盲测。scripted 成绩只检验管线；live 和 strict-replay 必须分列、按模型分别报告。场景完成率使用明确终态和真实规则/回执/审批/MFA/派发事实，不能使用展示文案包含关系。
